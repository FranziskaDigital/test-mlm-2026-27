# Gemeinsame Übungsdaten

Die Dateien in diesem Verzeichnis dienen nur den gemeinsamen Übungen.
Sie sind nicht Teil der Gruppenprojekte.

Enthalten sind kleine, selbst erzeugte Lehrbeispiele für:
- Bild
- Audio
- 3D
- Geodaten

Für Video liegt nur eine README bei; ein kleines Video kann in der Übung
mit FFmpeg selbst erzeugt werden.

# Dateinamenskonvention

## Schema

```text
<ID>_<Rolle>_<Version>.<Extension>
```

Beispiele:

```text
LDM-0001_master_v001.tif
LDM-0001_access_v001.webp
LDM-0001_thumb_v001.jpg
LDM-0012_master_v001.wav
LDM-0012_access_v001.mp3
LDM-0023_access_v001.mp4
LDM-0034_access_v001.glb
```

## Regeln

- keine Leerzeichen
- keine Umlaute
- Objekt-ID zuerst
- Dateiendung klein
- Versionsnummer dreistellig
- keine Dateinamen wie `final_neu2_wirklichfinal.jpg`
